# Release plan — TaskHUD v0.1.0

Status: planned, not released.

## Scope

The first packaged preview contains the local TODO workflow, human-reviewed agent proposals, the MCP and JSONL connectors, the compact desktop overlay and the English/French interface.

The release keeps the current local-first boundary. It does not require an account, a cloud service, telemetry or silent application of agent changes.
